⚙ System Settings
🔍 Scan vs Typing Detection
Controls how the system tells a barcode scanner apart from someone manually typing. Lower value = stricter (requires faster input to be treated as a scan).
Default: 80ms. Scanner bursts are typically 20-30ms per key. Human fast-typing is 80ms+.
🎭 Face Login & Liveness Detection
Liveness detection requires a genuine blink before accepting a face match, to prevent photo spoofing.
Default: 0.5. Lower = harder to match (fewer false accepts). Higher = easier (fewer false rejects).
Default: 0.22. Lower = only deep blinks count. Higher = even squinting triggers liveness.
Default: 18 frames (~6 seconds). Increase if operators are timing out before blinking.
